# Session 1 — Student checklist

- [ ] Our team has **one** fork of the teacher's repository.
- [ ] Everyone who needs to commit is invited as a collaborator to the team fork.
- [ ] I cloned our team fork on my computer.
- [ ] I installed project dependencies.
- [ ] I started the application and opened `/docs`.
- [ ] I tried `GET /products` and saw the sample items.
- [ ] Our team recorded its GitHub repository URL and member names outside the repository for the teacher.

You do **not** need to learn upstream syncing, rebase, Docker or CI/CD in this session.
