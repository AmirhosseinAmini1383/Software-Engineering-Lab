# تحلیل دامنه پروژه MiniOrder

# ۱. معرفی Domain اصلی سیستم

دامنه اصلی (Main Domain) پروژه MiniOrder، ثبت و مدیریت سفارش کالا است.

این سیستم یک API ساده برای نمایش کالاها، مشاهده مشخصات هر کالا، ثبت سفارش و مشاهده سفارش‌های ثبت‌شده است. هنگام ثبت سفارش، سیستم ابتدا بررسی می‌کند که کالای موردنظر وجود داشته باشد و تعداد درخواستی از موجودی آن بیشتر نباشد. سپس مبلغ کل سفارش از حاصل‌ضرب قیمت کالا در تعداد محاسبه می‌شود و سفارش با وضعیت اولیه `created` ثبت می‌گردد.

قابلیت‌های اصلی سیستم عبارت‌اند از:

- نمایش فهرست کالاها
- مشاهده اطلاعات یک کالای مشخص
- ثبت سفارش جدید
- بررسی موجودی و محاسبه مبلغ سفارش
- مشاهده سفارش‌های ثبت‌شده

بنابراین هدف اصلی MiniOrder، فراهم کردن امکان ثبت ساده سفارش کالا و مدیریت اطلاعات مربوط به آن است.
