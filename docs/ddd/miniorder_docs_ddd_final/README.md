# MiniOrder — مستندات تحلیل دامنه با DDD

این پوشه شامل مستندات تحلیل دامنه پروژه MiniOrder بر اساس Domain-Driven Design (DDD) است.

## فایل‌ها
- `domain-analysis.md`: هر هفت مرحله تحلیل دامنه.
- `context-map.md`: توضیح ارتباط محدوده‌های دامنه.
- `context-map.mmd`: نمودار Context Map با قالب Mermaid.

## نکته درباره وضعیت پیاده‌سازی
این مستند بین کد فعلی و طراحی پیشنهادی تفاوت قائل می‌شود. در نسخه فعلی، داده‌های کالا و سفارش در حافظه نگهداری می‌شوند؛ بررسی موجودی داخل منطق ثبت سفارش انجام می‌شود و موجودی پس از ثبت سفارش کاهش پیدا نمی‌کند. بنابراین Inventory در این تحلیل یک مسئولیت مفهومی پیشنهادی است، نه یک سرویس مستقل پیاده‌سازی‌شده.
